# Blueprint Garden  
*A living archive of home-improvement designs, system plans, architectural explorations, and experimental ideas.*

---

## 🌿 Purpose  
**Blueprint Garden** documents the evolution of a multi-disciplinary home ecosystem. It integrates:  
- Design sketches (2D + 3D)  
- CAD / PlantUML diagrams  
- Architecture & system-engineering notes  
- Renovation plans and decision-rationale  
- Gardening layouts, landscape systems and soil/irrigation experiments  
- Public product manuals and care documentation
- Brainstorm sessions, prototypes and lessons learned  

This repository isn’t a static collection—it’s a workspace where ideas grow, iterate and connect.

---

## 🧭 Guiding Principles  
- **Architect first, build second.** Start with intent, then execution.  
- **Systems over fragments.** Projects are interconnected, not isolated.  
- **Version everything.** Plans evolve; documentation captures why and how.  
- **Exploration is the point.** Creativity and rigor are equally valid.  
- **Public-friendly.** No personal or private data; everything is appropriate for a public portfolio.

## 🏗 Featured Projects  
- **Shed** — spatial layout, HVAC decisions, waterproofing, multi-use design.  
- **Utility Alley** — storage optimisation, workflow ergonomics, weatherproofing.  
- **Garage Office** — structural layout, daylighting, HVAC & door interfaces.  
- **North8** — narrow bed planting strategy, micro-climate engineering, elevated deck concept.  
- **Drybed12** — raised-bed in dry conditions, wicking reservoir design, water-retention strategy.  

Each project includes:  
- Problem definition & constraints  
- Key measurements  
- Design alternatives  
- Final plan & rationale  
- Versioned diagrams, sketches, models

## 🧰 Tools & Tech

## 🚀 Goals  
- Develop a long-term knowledge system capturing architectural intent, technical decisions, and build sequences.  
- Create high-fidelity planning before breaking ground.  
- Maintain a digital twin of the property ecosystem (home + garden + built systems).  
- Demonstrate technical and systems thinking applied to real-world built environments.
